![Airdrop](https://airdropmc.com/assets/airdrop-title.png)

Airdrop is a Paper plugin that allows configurable "packages" to be dropped in from the sky.

Packages are groups of items that can be configured with permissions and a price. The package when ordered / called in arrives from the sky in a crate, carried by a chicken parachute!

See the wiki for commands and configuration instructions: [Wiki](https://github.com/LukeMccon/Airdrop/wiki)
